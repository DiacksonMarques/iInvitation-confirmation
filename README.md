# 🎉 Invitation Confirmation

**Invitation Confirmation** é uma aplicação web desenvolvida para facilitar o gerenciamento de convites, confirmação de presença e lista de presentes para eventos.

O projeto tem como objetivo oferecer uma experiência simples, intuitiva e responsiva, permitindo que os convidados confirmem sua participação e escolham presentes disponíveis de maneira prática.

## 🚀 Tecnologias

As principais tecnologias utilizadas no desenvolvimento são:

- [Angular 22](https://angular.dev/) — Framework para desenvolvimento da aplicação.
- [TypeScript](https://www.typescriptlang.org/) — Linguagem principal.
- [SCSS](https://sass-lang.com/) — Estilização e organização dos estilos.
- [Node.js](https://nodejs.org/) — Ambiente de execução.
- [NPM](https://www.npmjs.com/) — Gerenciamento de dependências.

## ✨ Funcionalidades

### 📩 Confirmação de presença
- Consulta de convidados cadastrados.
- Confirmação ou recusa de presença no evento.
- Registro da resposta de cada convidado.
- Interface intuitiva e adaptada para dispositivos móveis.

### 🎁 Lista de presentes
- Exibição dos presentes disponíveis.
- Controle de quantidade disponível por presente.
- Seleção de presentes pelos convidados.
- Atualização automática das quantidades.
- Ocultação automática de presentes esgotados.

### 📊 Gerenciamento
- Controle de disponibilidade dos presentes.
- Prevenção de reservas acima da quantidade disponível.
- Organização das informações dos convidados e presentes.

## 🛠️ Instalação e execução

### Pré-requisitos

- Node.js
- NPM
- Angular CLI

### Clonar o repositório

```bash
git clone https://github.com/SEU-USUARIO/iInvitation-confirmation.git
```

### Acessar o projeto

```bash
cd iInvitation-confirmation
```

### Instalar as dependências

```bash
npm install
```

### Executar a aplicação

```bash
ng serve
```

A aplicação estará disponível em:

```text
http://localhost:4200
```
